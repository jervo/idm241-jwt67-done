Social Media Buttons

Vimeo, Github, Codepen & Flickr buttons located on the top, right side of screen in the section labeled "FOLLOW:"

TRIGGERS:

  • Hover ON
  • Hover OFF
  • Click

RULES:

  • Hover ON:
    • Cursor changes to Finger
    • Button icon opacity changes to 100%
  • Hover OFF:
    • Cursor changes back to default
    • Button icon opacity changes back to 50%
  • Click:
    • Browser window opens in a new tab

FEEDBACK:
